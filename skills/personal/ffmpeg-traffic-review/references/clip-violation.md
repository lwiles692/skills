# 截取证据视频

仅在需要导出事件视频时使用此说明。脚本用 bash 编排文件与参数，所有视频处理使用 ffmpeg，要求 ffmpeg 提供 `libx264`、AAC 和 PNG 编码器。

## 准备证据信息

从原视频确认事件区间、同一车辆号牌可辨认的时刻及完整号牌。实际拍摄日期和时间优先来自可核实的画面时间或用户提供的拍摄起点与视频偏移；文件元数据中的 `creation_time` 可能表示转码或创建时间，不能直接视为拍摄时间。

所有位置参数使用原视频相对时间，接受秒数或 `HH:MM:SS`，小数部分最多 3 位。命名时间单独使用 `YYYY-MM-DD_HH-MM-SS`，表示事件的实际拍摄时刻，采用拍摄地点的当地时间。

## 调用脚本

以下命令使用虚构日期和号牌。将 `INPUT_VIDEO` 替换为原视频的绝对路径，将 `OUTPUT_DIR` 替换为交付目录，并将事件时间、拍摄时间、号牌及行为替换为已核实的值：

```bash
TRAFFIC_SKILL_DIR="$HOME/.agents/skills/ffmpeg-traffic-review"
bash "$TRAFFIC_SKILL_DIR/scripts/traffic_video.sh" clip \
  --input "INPUT_VIDEO" \
  --start 00:01:23.500 \
  --end 00:01:27.000 \
  --plate-time 00:01:29.000 \
  --time 2026-01-02_10-15-23 \
  --plate 粤A12345 \
  --violation 一次连续变换两条及以上车道 \
  --output-dir "OUTPUT_DIR"
```

技能安装位置不同时，将 `TRAFFIC_SKILL_DIR` 设为本次读取的 `SKILL.md` 所在目录。`clip` 调用随附的 `clip_violation.sh`，并复用 `frame` 操作提取号牌核对图。ffmpeg 不在 `PATH` 或常见位置中时，添加 `--ffmpeg` 和已有可执行文件路径，或设置 `FFMPEG_BIN`。

调用参数的作用如下：

| 参数 | 内容 |
|---|---|
| `--input` | 原视频路径 |
| `--start`、`--end` | 事件的开始和结束位置，可以相同以表示一个关键时刻 |
| `--plate-time` | 已目视确认号牌清晰的原视频位置 |
| `--time` | 事件实际拍摄日期和时间，必填，不自动推断 |
| `--plate` | 已确认的完整号牌，必填，脚本不执行号牌识别 |
| `--violation` | 行为名称，由视觉复查结果确定 |
| `--output-dir` | 输出目录，缺失时创建 |

脚本优先截取 15 秒，并将事件放在片段中间，再根据片头、片尾及号牌时刻调整截取起点。源视频为 6–15 秒时完整保留；完整事件与号牌时刻跨度超过 15 秒时，延长片段以同时覆盖。源视频不足 6 秒时明确失败。

## 核对输出

脚本输出三个同名文件：

- `.mp4`：通常 15 秒、至少 6 秒的完整画面，使用 H.264 CRF 12 高质量编码，保留分辨率和原始帧时间间隔，不降到复查抽样帧率。有音轨时转为 AAC。
- `.png`：从原视频的号牌时刻提取的完整画面，不缩放或增强。帧按实际视频时间点选取，定位精度受源帧间隔限制。
- `.txt`：原视频路径、事件和号牌定位、片段范围、调用方提供的拍摄时间及号牌，便于回溯。

上述示例的视频名称为 `2026-01-02_10-15-23-粤A12345-一次连续变换两条及以上车道.mp4`。

检查 PNG 中是否能逐字符确认号牌，并查看导出视频相应时刻的原分辨率画面，确认同一车辆及号牌仍可辨认。编码质量和原图保存不能使原本模糊的号牌变得可读；仅运行成功不能代替目视核对。

脚本独立解码导出的视频轨道，确认至少 6 秒，并校验与所选片段时长的偏差不超过 0.1 秒。源视频不足 6 秒、定位越界、取不到号牌帧、编码失败或文件重名时，明确失败并清理本次临时输出，不覆盖已有文件，不填充重复帧。
